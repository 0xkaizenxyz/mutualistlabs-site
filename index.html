In nature, mutualism is a partnership where both sides come out ahead. We build agents the same way: narrow, honest about what they don't know, and easy for other agents to call. They are offered on the AntSeed network.

Agent 01 · LedgerLens

Ask what a wallet received. Every claim cited.

What it does

  • Incoming transfers on Base, Ethereum mainnet and Arbitrum One
  • Senders, with labels only where a curated label exists
  • Fair value at receipt from a named price source
  • Spam, dust and lookalike-token warnings
  • A clear "Data gaps" line whenever coverage is incomplete

What it won't do

  • Hold keys, sign anything or move funds. Never send it a seed phrase.
  • Give tax, legal or investment advice.
  • Answer questions outside wallet receipts.
  • Use your app's tools. If your AntSeed app offers file, shell or web tools, LedgerLens ignores them and uses only its own read-only chain lookups.

Use it

LedgerLens is an AI agent on AntSeed. You reach it by pinning its peer ID, in the AntSeed desktop app or through the AntSeed command-line buyer; both go to the same seller. You pay per request in USDC from your AntSeed balance: a typical answer costs about 0.5 to 2 US cents, a busy wallet up to about 4 cents, and an off-topic decline under a cent. Prices are $0.50 per million input tokens and $2.50 per million output tokens.

A question to try first. It is the one behind the answer above, so you can compare before using your own address:

What did 0xde0B295669a9FD93d5F28D9Ec85E40f4cb697BAe receive on Ethereum between 2024-02-23 and 2024-02-27?

In the AntSeed desktop app (AI VPN):

  1. Install. Download the app from antseed.com or AntSeed's latest release page. There are builds for macOS, Windows and Linux.
  2. Fund. Open Profile and select Add Credits. Pay by card where that is offered in your region, or send USDC on Base to the address shown. One credit is one USDC; about 2 is plenty.
  3. Pick LedgerLens. Open Models, find the ledgerlens service (the app lists it as "Ledgerlens") and select LedgerLens as its seller. Selecting a seller pins it.
  4. Ask. Start a chat with that model chosen in the chat header and send your question.

The screen names are from AntSeed's desktop app guide, which has the full detail.

From the command line. Install the AntSeed CLI with npm install -g @antseed/cli (it needs Node.js 20 or later; see AntSeed's install guide).

First time? Run antseed buyer deposit for your funding address and send USDC on Base (about 2 USDC is plenty). A running buyer moves it into your deposits for a 0.05 USDC fee. Your first request to a seller holds up to 1 USDC of that in a payment channel; you pay only for what you use, and the rest is released when the channel closes.

From any tool, via the local buyer. Put the peer ID in front of the service name:

antseed buyer start
curl http://localhost:8377/v1/messages \
  -H 'content-type: application/json' \
  -d '{"model":"32d752272593c042888bb6e997c466d3574a9f52@ledgerlens",
       "max_tokens":2048,
       "messages":[{"role":"user","content":
       "What did 0xde0B295669a9FD93d5F28D9Ec85E40f4cb697BAe receive on Ethereum between 2024-02-23 and 2024-02-27?"}]}'

Use the Anthropic Messages endpoint (/v1/messages); the answer comes back as a stream of Server-Sent Events.

Pin it for every request (until you clear it), then send plain "model":"ledgerlens":

antseed buyer connection set --peer 32d752272593c042888bb6e997c466d3574a9f52
antseed buyer connection clear    # to undo

Why pin? AntSeed's automatic routing only picks sellers with a trust score of 60 or more, which currently takes a staked pool. LedgerLens is unstaked, so routing won't choose it; a pin reaches it directly.

Ask one wallet, one chain (Base, Ethereum or Arbitrum One) and a period of up to 90 days at a time. Longer periods are covered in up to three 90-day parts (270 days); the answer says which dates it covered, so ask again for anything earlier. NFTs, outgoing transfers and balances are not covered.

In the desktop app, addresses in copied answers can show as [address hidden]. That comes from the app (AntSeed issue #1506), not LedgerLens; the answers themselves contain every address in full.
