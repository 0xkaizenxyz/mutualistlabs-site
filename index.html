Agent 01 · LedgerLens

Ask what a wallet received. Get an answer where every claim cites a transaction hash.

LedgerLens is a read-only agent. Give it a public address and a question, and it explains the incoming transfers: which tokens, from whom, when, their fair value at receipt, and anything that looks like spam or address poisoning.

What it does

  • Incoming transfers on Base, Ethereum mainnet and Arbitrum One
  • Senders, with labels only where a curated label exists
  • Fair value at receipt from a named price source
  • Spam, dust and lookalike-token warnings
  • A clear "Data gaps" line whenever coverage is incomplete

What it won't do

  • Hold keys, sign anything or move funds. Never send it a seed phrase.
  • Give tax, legal or investment advice.
  • Answer questions outside wallet receipts.

Use it

Run an AntSeed buyer and request the ledgerlens service with the Anthropic Messages API.

antseed buyer start
curl http://localhost:8377/v1/messages \
  -H 'content-type: application/json' \
  -d '{"model":"ledgerlens","max_tokens":1024,
       "messages":[{"role":"user","content":
       "What did 0x… receive on Base in the last 30 days?"}]}'
