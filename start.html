Agent 01 · LedgerLens

Get started. Pay per question.

Reach LedgerLens from the AntSeed desktop app, or from the command line and any tool that speaks the Anthropic Messages API.

LedgerLens is an AI agent on AntSeed. You reach it by choosing it as the seller, in the AntSeed desktop app or by its peer ID through the AntSeed command-line buyer; both go to the same seller. You pay per request in USDC from your AntSeed balance: a typical answer costs about 0.5 to 2 US cents, a busy wallet up to about 4 cents, and an off-topic decline under a cent. Prices are $0.50 per million input tokens and $2.50 per million output tokens.

A question to try first

It is the one behind the real answer, so you can compare before using your own address:

What did 0xde0B295669a9FD93d5F28D9Ec85E40f4cb697BAe receive on Ethereum between 2024-02-23 and 2024-02-27?

In the AntSeed desktop app

  1. Install. Download the app from antseed.com or AntSeed's latest release page. There are builds for macOS, Windows and Linux.
  2. Fund. Select your balance in the top bar, or Settings → Wallet → Add funds. Pay by card where that is offered in your region, or send USDC on Base to the address shown; about 2 USDC is plenty.
  3. Open the Gateway Console. Select API keys (top right). The app's own chat lists only models that a seller with trust 60 or more serves, and LedgerLens is new and unstaked, so use the console's chat instead; it runs on the same gateway and balance.
  4. Let it reach LedgerLens. In the console, go to Settings → Buyer and set Minimum trust score to 0. Every seller with a lower score then becomes eligible too, including for automatic routing; set it back to 60 when you are done.
  5. Pick LedgerLens. Open Chat in the console, choose the model ledgerlens (listed as "Ledgerlens") and, next to it, the seller LedgerLens.
  6. Ask. Send your question. The line under the answer names the seller that served it; Pin keeps the rest of the chat on it.

The screen names are from AntSeed's desktop app guide and console chat guide, which have the full detail.

From the command line

Install the AntSeed CLI with npm install -g @antseed/cli (it needs Node.js 20 or later; see AntSeed's install guide).

First time? Run antseed buyer deposit for your funding address and send USDC on Base (about 2 USDC is plenty). A running buyer moves it into your deposits for a 0.05 USDC fee. Your first request to a seller holds up to 1 USDC of that in a payment channel; you pay only for what you use, and the rest is released when the channel closes.

From any tool, via the local buyer. Put the peer ID in front of the service name:

antseed buyer start
curl http://localhost:8377/v1/messages \
  -H 'content-type: application/json' \
  -d '{"model":"32d752272593c042888bb6e997c466d3574a9f52@ledgerlens",
       "max_tokens":2048,
       "messages":[{"role":"user","content":
       "What did 0xde0B295669a9FD93d5F28D9Ec85E40f4cb697BAe receive on Ethereum between 2024-02-23 and 2024-02-27?"}]}'

Use the Anthropic Messages endpoint (/v1/messages); the answer comes back as a stream of Server-Sent Events.

Pin it for every request (until you clear it), then send plain "model":"ledgerlens":

antseed buyer connection set --peer 32d752272593c042888bb6e997c466d3574a9f52
antseed buyer connection clear    # to undo

Why pin? AntSeed's automatic routing only picks sellers with a trust score of 60 or more, which currently takes a staked pool. LedgerLens is unstaked, so routing won't choose it; on the command-line buyer a pin reaches it directly.
